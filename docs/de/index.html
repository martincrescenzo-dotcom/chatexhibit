So exportieren Sie einen Chat

WhatsApp: Chat → Name/⋮ → Chat exportieren → mit Medien (zip).
Telegram: Telegram Desktop → ⋮ → Chatverlauf exportieren → Format JSON.
LINE: Chat → ≡ → Einstellungen → Chatverlauf exportieren (.txt).
KakaoTalk: Chat → ≡ → ⚙ → Exportieren (Text).
