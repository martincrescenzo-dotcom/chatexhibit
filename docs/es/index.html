Cómo exportar un chat

WhatsApp: chat → nombre/⋮ → Exportar chat → con archivos (zip).
Telegram: Telegram Desktop → ⋮ → Exportar historial → formato JSON.
LINE: chat → ≡ → Ajustes → Exportar historial (.txt).
KakaoTalk: chat → ≡ → ⚙ → Exportar (texto).
