How to export a chat

WhatsApp: chat → name/⋮ → Export chat → with media (zip).
Telegram: Telegram Desktop → chat ⋮ → Export chat history → format JSON.
LINE: chat → ≡ → Settings → Export chat history (.txt).
KakaoTalk: chat → ≡ → ⚙ → Export chat (text).
Messenger / Instagram: Accounts Center → Your information and permissions → Download your information → Messages, format JSON.
Discord: Discord has no built-in export; export the DM or channel with the open-source DiscordChatExporter in JSON or CSV format, then load that file here.
