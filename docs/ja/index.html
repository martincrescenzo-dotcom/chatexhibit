トーク履歴のエクスポート方法

LINE: トーク → ≡ → 設定 → トーク履歴を送信 (.txt)。
WhatsApp: チャット → 名前/⋮ → チャットをエクスポート。
Telegram: Telegram Desktop → ⋮ → チャット履歴をエクスポート → JSON。
KakaoTalk: チャット → ≡ → ⚙ → 대화 내보내기。

証拠用エディションを有効化（9ユーロ・買い切り）番号付き全文反訳、省略部分が分かる抜粋、ロゴなし。1回の支払いでこのブラウザで利用可能。Stripeによる安全な決済。14日以内のお申し出で返金。

証拠のような番号付け

各メッセージに元ファイル内の位置に対応する番号（A-0001、A-0002…）を付与します。

SHA-256ハッシュ

表紙に読み込んだファイルの名前・サイズ・SHA-256を記載し、PDFと元ファイルの一致を確認できます。

プライバシー
