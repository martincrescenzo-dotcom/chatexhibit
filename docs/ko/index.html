대화 내보내는 방법

카카오톡: 채팅방 → ≡ → ⚙ 설정 → 대화 내보내기 → 텍스트만 보내기.
LINE: 채팅 → ≡ → 설정 → 대화 내용 내보내기 (.txt).
WhatsApp: 채팅 → 이름/⋮ → 채팅 내보내기.
Telegram: Telegram Desktop → ⋮ → 대화 기록 내보내기 → JSON.

증거용 버전 활성화, 9유로 1회 결제번호가 매겨진 전체 녹취록, 생략 구간이 표시된 발췌, 표시 없음. 1회 결제로 이 브라우저에서 사용. Stripe 보안 결제. 14일 이내 요청 시 환불.

증거처럼 번호 부여

모든 메시지에 원본 파일 내 위치와 일치하는 번호(A-0001, A-0002...)가 붙어 일부만 골랐다는 의심을 줄입니다.

SHA-256 해시

표지에 불러온 파일의 이름, 크기, SHA-256 해시를 기록하여 PDF와 원본 파일의 일치를 확인할 수 있습니다.

파일은 브라우저에서만 읽힙니다. 업로드, 회원가입, 서버 없음.
