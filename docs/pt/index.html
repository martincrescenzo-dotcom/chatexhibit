Como exportar uma conversa

WhatsApp: conversa → nome/⋮ → Exportar conversa → com mídia (zip).
Telegram: Telegram Desktop → ⋮ → Exportar histórico → formato JSON.
LINE: conversa → ≡ → Configurações → Exportar histórico (.txt).
KakaoTalk: conversa → ≡ → ⚙ → Exportar (texto).
