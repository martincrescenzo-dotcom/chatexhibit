Comment exporter une conversation

WhatsApp : conversation → nom/⋮ → Exporter la discussion → avec médias (zip).
Telegram : Telegram Desktop → ⋮ → Exporter l'historique → format JSON.
LINE : conversation → ≡ → Paramètres → Exporter l'historique (.txt).
KakaoTalk : conversation → ≡ → ⚙ → Exporter (texte).
