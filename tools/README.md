# WhatsApp chat export to printable HTML / PDF (offline, free)

`python3 whatsapp_to_html.py "_chat.txt" > chat.html`, then open it in a browser and Print > Save as PDF. Python 3 standard library only, nothing uploaded. Handles Android and iOS export formats and multi-line messages.

For court, HR, insurance or landlord disputes, [ChatExhibit](https://martincrescenzo-dotcom.github.io/chatexhibit/) does this in the browser and adds a cover sheet, numbered pages, a SHA-256 hash of the original export, and Telegram, Signal, Messenger, Instagram, Discord, Slack and Google Chat support.
